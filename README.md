# My Portfolio — okoyo13

## About the Project

This is my personal portfolio website, showcasing my background, projects, and contact information.

The website was built using HTML and CSS, with a focus on semantic HTML, accessibility, and responsive design.

## Pages

- **Home (`index.html`):** Introduction and portfolio overview.
- **About (`about.html`):** Background, skills, and experience.
- **Projects (`projects.html`):** Projects and work.
- **Contact (`contact.html`):** Contact information.

## Features

- Responsive navigation
- Semantic HTML structure
- Accessibility considerations
- Mobile-friendly layout

## Lessons Learned

1. **Semantic HTML:** I learned how to use elements such as `<nav>`, `<address>`, `<figure>`, `<figcaption>`, `<article>`, and `<time>` to give webpage content meaningful structure.
2. **HTML links:** I learned how to create email links using `mailto:`, phone links using `tel:`, and navigation links between pages.
3. **CSS layouts:** I practised using Flexbox to position a navigation menu and CSS Grid to arrange six images in a photo gallery.
4. **Images and accessibility:** I learned to use descriptive `alt` attributes for images and `<figcaption>` to provide captions in a gallery.
5. **Git and GitHub:** I practised creating folders, organizing files, updating file paths, staging changes, committing them, and pushing changes to GitHub.
6. **Markdown links and file organization:** I learned that moving an image into a different folder requires updating references to its new relative path.

## Challenges Faced

1. **Organizing screenshots:** Moving screenshots into the `images/` folder meant updating the image path in `devtools-exploration.md`. I corrected the link to use `images/Betika-screenshot.png`.
2. **Building a navigation menu:** Positioning the site name on the left and four navigation links on the right required practising Flexbox properties such as `display: flex` and `justify-content: space-between`.
3. **Creating a responsive gallery:** Arranging six images in a grid required using CSS Grid and adjusting the number of columns for smaller screens.
4. **Structuring contact information:** I practised using the correct HTML elements and link formats for an address, email, phone number, and social media profiles.
5. **Managing Git changes:** I learned that Git does not track empty folders, so I needed to add actual files before the new `daily-challenges/` folder could be committed.

These challenges helped me improve my HTML structure, CSS layout skills, file organization, and Git workflow.
